## Dictation dictionary — 2026-08-28
- Keys `dictateVocabulary: string[]` + `dictateReplacements: {id,from,to}[]`. Pipeline: STT (OpenAI `keywords` = vocab + speakable rule `to`, or spoken `from` when `to` is email/URL; `prompt` = base + preferred terms + `"heard" → write`; mint + `session.update` via overlay payload) → optional improve (builtin/custom prompt + suffix from vocab/rules, do not mutate stored `dictate-cleanup`) → `applyReplacements` (case-insensitive Unicode word-boundary, longest `from` first) → clipboard. Rules run even if Don’t rewrite. Apple Speech and Parakeet have no vocab API — prompt/keywords unused; replace + cleanup suffix still apply. Speakable `to` (no `@`/URL) also added to vocab on learn-from-copy Add.
- Learn-from-copy: after insert/copy-only, arm `{text,at}` 5min. Last insert is matched as a token window inside the copy (whole-document copy). Emails are one token (`user@host.tld`). Similar = ≥35% equal tokens in that window, or char-LCS ≥0.5 on short snippets with a substitution. Pair `from`/`to` need char-LCS ≥0.4 (drops random URL copies). Similar copy does not increment `copyCount`. Status toast Add/Skip; skip/timeout/hide = no write. Spoken-email `from` up to 12 tokens. LCS backtrack emits del-then-ins so `use state`→`useState` is a pair.
